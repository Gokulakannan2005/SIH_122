BUG-001: Misleading Global Header Confidence Badge ("Auto-Match: 53% High Conf")
--------------------------------------------------------------------------------
SEVERITY: Medium (UX / Information Integrity Issue)
DATE RESOLVED: September 6, 2026
AFFECTED COMPONENT: frontend/src/components/AppHeader.tsx

PROBLEM STATEMENT / USER REPORT:
A persistent pill badge reading "Auto-Match: 53% High Conf" was rendered in the
top-right application header across every tab and view (Supervisor Hub, Dashboard,
Daily Field Reports Feed, AI Auto-Match Matrix, Baseline Schedule, and Copilot).
This presented several critical issues:
  1. Misleading Aggregate Metric: A single global percentage cannot accurately
     represent individual field report alignments, active review queues, or overall
     project health.
  2. Rule Conflict / Inaccurate Wording: A 53% score was labeled "High Conf",
     violating the core project confidence rules (where >= 75% is High Confidence/Ready,
     40–74% is Review Required, and < 40% is Low Confidence/Unplanned).
  3. Lack of Context: Confidence scores must always remain contextual to specific
     field updates, matching candidates, and inspector breakdown cards.

ROOT CAUSE ANALYSIS:
In `frontend/src/components/AppHeader.tsx`, a calculation was performing:
  `const readyCount = siteUpdates.filter(u => matchResults[u.id]?.category === 'ready').length;`
  `const highConfPct = totalCount > 0 ? Math.round((readyCount / totalCount) * 100) : 0;`
This fraction of ready items was hardcoded to display with the label `{highConfPct}% High Conf`
in the persistent header bar, incorrectly mixing portfolio-level match counts with
individual item confidence levels.

RESOLUTION / CODE MODIFICATIONS:
  - Removed `highConfPct`, `totalCount`, and `readyCount` calculations from `AppHeader.tsx`.
  - Removed the `<div className="mono-pill">Auto-Match: {highConfPct}% High Conf</div>`
    element entirely from `AppHeader.tsx`.
  - Cleaned up unused Lucide icons (`CheckCircle2`, `Sparkles`, `Database`) from `AppHeader.tsx`.
  - Preserved the remaining header controls (Lead Planner / Supervisor Role Toggle,
    Export CSV, and Restart Demo) with balanced flexbox spacing and clean responsive alignment.
  - Confirmed that contextual confidence scores remain active and correctly displayed
    on individual records in:
      * Daily Field Reports Kanban & Table rows (showing exact % score and category).
      * Planner Review Queue (sorted by confidence score with explicit status badges).
      * Inspector Drawer (displaying detailed score breakdown: Keyword, Discipline,
        Spatial Area, and Fuzzy tokens).
      * Planner Review AI Top Recommendation card (annotating reasons and breakdowns).

VERIFICATION PERFORMED:
  1. Build Verification: Ran `npm run build` (`tsc && vite build`) — passed with 0 errors.
  2. Global Header Inspection: Verified that the "Auto-Match: 53% High Conf" badge is absent
     across all navigation views (Dashboard, Daily Field Reports, Schedule Baseline,
     Planner Review Workbench, Supervisor Entry, AI Copilot, and Data Ingestion).
  3. Responsive Header Layout: Verified header flex spacing remains balanced at laptop width.
  4. Contextual Confidence Integrity: Confirmed threshold wording strictly follows standard:
       * >= 75%: Ready / High Confidence candidate
       * 40–74%: Review required
       * < 40%: Low confidence / Unplanned scope candidate
